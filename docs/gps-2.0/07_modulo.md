# 07 — Regularidade documental

## Escopo
Três categorias permanentes: plano, termo e justificativa. Permitir obrigações temporárias configuráveis pelo CEC.

## Regras de negócio
Plano até segundo dia útil do mês, calendário de feriados validado; justificativa quando aplicável até último dia do mês. Termos com prazo configurado conforme norma. D-7 popup, D-2 popup/email, após prazo cobrança com legislação validada. Verde no prazo, amarelo entregue atrasado, vermelho vencido pendente, azul a vencer, cinza não aplicável.

## Critérios mínimos de aceite
Entrega interrompe cobrança correspondente, mantém histórico; 1x1 não é obrigação documental PEC.

## Implementação
Inspecionar código existente; registrar dependências, migrações, testes e pendências. Não declarar concluído sem evidência.
