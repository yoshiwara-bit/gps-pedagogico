# 01 — Arquitetura

## Escopo
Apps Script V8, HTML/CSS/JS, Sheets como base estruturada, Drive para originais, GitHub para versões. Node apenas testes locais. Separar demonstração, laboratório e produção.

## Regras de negócio
IDs estáveis, esquema versionado, migrações idempotentes, serviços desacoplados e configuração privada. Não exigir Cloud Console, servidor Python ou Streamlit.

## Critérios mínimos de aceite
Instalação repetida não duplica tabelas; demonstração não acessa dados reais.

## Implementação
Inspecionar código existente; registrar dependências, migrações, testes e pendências. Não declarar concluído sem evidência.
